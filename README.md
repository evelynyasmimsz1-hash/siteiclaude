# Imob Flow Lab

Landing page do laboratório de automação e IA para imobiliárias e construtoras.

## Site no ar

- **Produção:** https://evelynyasmimsz1-hash.github.io/siteiclaude/
- **Preview rápido:** https://raw.githack.com/evelynyasmimsz1-hash/siteiclaude/gh-pages/index.html

## Estrutura

```
index.html      Página única com todas as seções
styles.css      Estilos (paleta P&B + accent amber)
script.js       Interações (parallax, partículas, form, animações)
assets/         Logo e favicon
```

## Como rodar localmente

```bash
python3 -m http.server 8000
# abre http://localhost:8000
```

## Branches

- `main` — código fonte do site na raiz (este branch)
- `gh-pages` — espelho da `main`, serve o GitHub Pages
- `claude/clever-rubin-0h0Sj` — branch de trabalho, mantém o site dentro de `/site/`
